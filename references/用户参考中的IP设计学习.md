# 用户参考中的IP设计学习

本文件从用户认可的45例中提炼IP设计方法。学习的是角色与信息、场景和品牌之间的关系；不得复制参考中的角色造型、品牌标识、服装细节或完整动作。

## 1. 先确定IP职责

| 职责 | 画面位置与尺度 | 适合内容 | 风险 |
|---|---|---|---|
| 英雄主体 | 中下部或视觉中心，尺度仅次于标题 | 月度主题、运动、公益 | 只放大角色却没有动作和事件 |
| 叙事参与者 | 与人物、地标、器具共同完成动作 | 节庆、观影、亲子、社区活动 | 像独立贴纸，没有视线与接触 |
| 概念承载者 | 站在或操控海豚、漂流瓶、球等核心物件 | 主题KV、系列封面 | 概念物件与标题无关 |
| 栏目主持 | 固定位置、稳定比例，动作随期数变化 | 月报、周报、活动回顾 | 每期只换背景，角色没有新信息 |
| 信息向导 | 靠近步骤、问题或箭头，尺度克制 | 服务解释、流程长图 | 抢过正文，降低专业可信度 |

一张图可出现多个角色，但主IP只承担一个首要职责。职责变化要靠位置、比例、动作和视线完成，不能只靠文案说明。

## 2. 角色设计的六层结构

1. **识别核：** 固定头身比、头部轮廓、眼鼻嘴关系、标志性发饰/顶饰、胸标和主品牌色。换媒介也不能丢。
2. **动作剪影：** 缩成黑色后仍能辨认骑乘、上篮、观影、带路或展示。手脚角度服务动作，不为可爱随意弯曲。
3. **表情强度：** 活动预告可开口和高眉；公益守护宜温和克制；服务说明宜友好但不戏剧化。表情与内容强度一致。
4. **服装与道具：** 只替换任务相关层，如球衣、观影零食、节庆配饰；脸、身体母型和核心标志保持不变。
5. **媒介表面：** 平涂、纸感、3D软胶、厚涂或线描均可，但轮廓粗细、阴影方向、材质高光须与环境同场。
6. **接触与视线：** 脚踩、手握、身体倚靠、视线追随和投影至少成立一项；没有接触关系就容易像贴纸。

## 4. 系列化而非反复换皮

固定的是识别核、品牌色角色、轮廓语言与一个系列锚点；变化的是动作、任务道具、场景关系和局部服装。建议建立角色矩阵：

| 维度 | 固定 | 可变 |
|---|---|---|
| 身份 | 头身、脸、标志、核心色 | 表情幅度、视线方向 |
| 行为 | 动作曲线的性格 | 走、跑、跳、坐、指引、骑乘 |
| 主题 | 品牌语气 | 球衣、节庆小物、专业器具 |
| 环境 | 接触真实、光向统一 | 海洋、球场、影院、城市、信息卡 |
| 版式 | 系列固定识别区 | 角色尺度、图文穿插与出场位置 |

若同系列两张只更换标题和背景，不算IP叙事延展。至少改变一项“角色正在做什么、与什么发生关系、这个关系如何解释主题”。

## 5. IP与标题的五种关系

- **托举：** IP或概念物件承托标题下缘，适合英雄型KV。
- **穿插：** 手、球、浪花或道具进入字块，但不能遮住关键笔画。
- **同向：** 动作弧线与斜体/书法走势一致，适合运动和热闹活动。
- **对视：** 角色视线指向日期、步骤或行动号召，适合信息长图。
- **留场：** 标题占强势上部，IP在下部环境中完成叙事，适合系列封面。

不能用“标题上方放IP、右下角再放一个IP”解决空白。每次出现都要有信息职责。

## 6. 生成与验收

生成前准备一张正面标准像、至少一张侧面或动作参考、品牌色与不可变特征清单。先做单角色动作小样，再进入复杂场景；需要准确Logo和胸标时分层合成，不让模型凭空重画。

逐项检查：

- 遮住文字后，仅看轮廓还能认出角色和动作吗？
- 头身、脸型、五官间距、顶饰/发饰、胸标是否与设定一致？
- 手脚是否真实接触道具或地面，投影方向是否一致？
- 表情是否符合内容，而非所有场景都同一张大笑脸？
- 道具和服装是否解释主题，还是随意增加可爱元素？
- IP与标题、场线或环境是否形成同一条视觉动线？
- 缩略图下IP是否仍可识别；若太小，它是否应改为信息向导而非主角？
- 系列延展是否真正改变动作和关系，同时保留识别核？
