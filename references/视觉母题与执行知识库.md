## 使用方法

本库不是给用户看的风格菜单。根据任务、营销目标、素材和渠道内部匹配1–3个母题，再转写成具体方案。一个方案可以组合一个主母题和一个辅助母题，但第一视觉只能有一个。所有百分比、焦段和人数都是帮助起稿的参考区间，不是通用规范；可根据画幅、渠道、产品露出与创意需要突破，并说明理由。

### 生成前锁版卡

进入生成或合成前，内部形成一张简短锁版卡；用户已经确认的项目不得被模型自行改写：

| 项目 | 必须写清 |
| --- | --- |
| 画幅 | 比例、像素或实际制作尺寸 |
| Logo | 官方文件、位置、宽度占比、安全区、是否允许反白/反金 |
| 文字 | 完整原文、层级、位置、最大行数、对齐方式 |
| 第一视觉 | 唯一主体、位置、面积占比、是否允许出框 |
| 配色 | 背景冷暖、主色、辅助色、品牌色角色与综合色偏移 |
| 素材 | 必须保持、允许变化、不得生成的事实资产 |
| 防漂移 | 不得新增、不得重复、不得变形的内容 |

锁版卡是生成验收依据，不是新的长篇交付格式。若生成结果违反Logo占比、核心数字唯一性、中文事实、IP比例或已确认配色，应先局部修正，不把错误结果直接交付。

## 高级感翻译器

| 类型 | 可执行视觉动作 | 避免 |
| --- | --- | --- |
| 静奢 | 少元素、大留白、天然材质、柔光、中长焦、低信息密度 | 无项目依据的金色堆饰、元素满画面 |
| 建筑高级 | 强调体块、结构、比例、材料和建筑摄影裁切 | 普通广角效果图 |
| Editorial | 非中心构图、图片裁切、文字参与构图、杂志网格 | PPT式图文排列 |
| 艺术高级 | 雕塑/装置/展览语境、单一强概念 | 无理由AI奇观 |
| 酒店高级 | 空间、灯光、材料、服务瞬间、安静人物 | 网红打卡感 |
| 奢侈品高级 | 单一主体、近景、极致材质、极少信息 | 多主体陈列 |
| 东方高级 | 石、水、木、庭院、留白、自然秩序 | 祥云鹤龙印章堆砌 |
| 城市高级 | 城市尺度、坐标、天际线、秩序与距离感 | 金色光轨 |
| 自然高级 | 山水林天空与空气占主导，建筑弱化 | 旅游风光片 |
| 圈层高级 | 人物状态、社交距离、空间与生活方式 | 集体看镜头 |
| 建筑学术 | 模型、图纸、材料、轴测、档案、出版物 | 工程汇报PPT |
| 未来高级 | 先进材料、玻璃、暖银金属、光域、超净空间 | HUD、代码、电路板 |
| 插画高级 | 原创造型、统一笔触、清楚色块、成熟人物比例、主次稳定、品牌适配 | 用米黄、低饱和、纸张颗粒或大留白代替审美判断 |
| IP活动高级 | 锁定IP识别资产，以一个主图形串联少量内容暗示，人物与IP同媒介 | 吉祥物贴图、活动项目大拼盘、摄影与卡通混用 |

高级不等于统一的灰、淡、静、少。高饱和、强对比、繁复装饰、热烈人群、明亮日光与夜景同样可以建立高品质，前提是视觉秩序清楚、材质可信、光源合理，并与品牌及传播目的相符。

插画高级也不等于米黄色背景、低饱和、复古纸张颗粒、修长人物或单纯减少元素。判断造型是否有原创识别度，IP与人物的线条/比例/明暗/颗粒是否统一，色块关系与第一视觉是否清楚，画面是否依赖贴纸、笑脸、水花等模板化符号。可选当代平面、编辑插画、丝网印刷、现代水彩、几何拼贴、时尚线描或品牌角色插画；根据品牌与受众选择，不把某一种媒介固定为“高级答案”。

## 30个视觉母题

### M01 建筑宣言
完整建筑体量或强轮廓为第一视觉。可从天空45%–65%、建筑位于下半部、轻低机位35–70mm开始探索；清晨、日间、黄昏和夜景均可选择。人物是否出现由尺度表达、生活方式和传播目标决定。适合城市封面、豪宅首发；避免没有光源逻辑的HDR、云缝光和发光轮廓。

### M02 建筑切片
聚焦转角、阳台、幕墙、柱网或雨棚，主体40%–70%并允许出框；70–120mm侧向柔光强化真实材质；文字放建筑外负空间。适合设计感强的建筑。

### M03 建筑收藏
把建筑当艺术产品，可从建筑25%–45%、极净背景和85–120mm开始探索；强调石材、金属、玻璃差异，采用建筑杂志式排版。人物可无，也可作为尺度与使用状态的克制证据。适合顶豪与高端改善。

### M04 建筑模型
米白/灰白模型置于同色无缝空间，顶侧柔光与真实投影，Ivory/Warm Grey，小而克制的文字。谨防窗洞、层数与结构被AI画错。

### M05 建筑图纸
以平面、立面、轴测、模型和材料样本组成建筑出版物式画面。适合建筑价值和大师项目，避免工程汇报感。

### M06 巨幅自然
自然70%–90%，建筑10%–25%；表达“建筑拥有自然”。使用低饱和真实空气透视，避免旅游风光和艳蓝天空。

### M07 水岸静境
水面45%–70%，有轻微波纹而非镜面；建筑水平延展；雾蓝灰加暖石灰，阴天晨光。避免无产品依据的游艇、香槟、满画面金光与大鸟群；品牌金既可点缀，也可在品牌与传播目标支持时扩大为主要识别色。

### M08 森林隐居
前景植物局部，中景林冠，建筑若隐若现；长焦压缩空间；灰绿和岩石色。避免热带度假酒店感。

### M09 天空资产
天空65%–80%，建筑只是克制的城市界面。适合高层、天际大平层与城市景观；天空无戏剧云与神光。

### M10 自然微观
以水纹、岩石、树皮、叶影、风吹织物或水滴为第一视觉，将自然价值转成品牌图形。必须保留与项目价值的清晰关联。

### M11 巨型雕塑
天然石、哑光金属或半透明玻璃雕塑承担第一视觉，建筑退为第二视觉。避免默认金色镜面鹿、马和无关动物。

### M12 艺术展览
像当代艺术展：一件主体、大留白、展签式信息和小字号。适合品牌期，不适合急促强销。

### M13 艺术静物
石块、陶瓷、花器、哑光金属或玻璃，以奢侈品静物摄影表达抽象价值。控制为一组主次清晰的物件，不做道具堆砌。

### M14 光影装置
半透明光幕、圆形光域、玻璃折射或建筑阴影成为第一视觉。光应有真实介质、方向与衰减，避免廉价激光束。

### M15 超现实艺术
允许建筑模型悬浮、石材裂开、巨型织物或抽象景观；必须先有品牌隐喻，再有奇观，且结构与阴影自洽。

### M16 静奢早餐
只保留杯、书、椅、窗和一束晨光中的少量元素；人物可无。用空间和选择表达生活，而非满桌食物。

### M17 窗边时刻
人物占8%–20%，45度背侧或侧面，不看镜头；强调空间、景观与独处。禁止“成功人士”摆拍。

### M18 酒店度假
泳池、Lounge、石材、毛巾、水与休息区围绕服务体验组织。人物不是主体，避免网红酒店高饱和滤镜。

### M19 社交会客
2–5人，自然姿态、有社交距离、无人集体看镜头；空间为第一视觉。适合会所、圈层和私宴。

### M20 城市漫游
用街区、艺术馆、咖啡、公园或滨水步道表达生活半径，项目可不出现。适合内容传播，不作为首发主KV首选。

### M21 当代东方
可用石、水、木、院、影、空，也可使用红金、祥云、鹤、龙、印章、水墨和民俗装饰。符号可以单一克制，也可以丰富繁复；关键是建立主次、重复规律、留白与材质系统，并与节庆、地域文化、品牌资产或工艺来源相关。

### M22 宋式克制
米灰、墨灰、微绿；不对称留白、极柔光、极少主体。表达秩序、含蓄和节制，不复刻古装或仿古场景。

### M23 时间
用日影、老树、石材、光线移动与轻微使用痕迹表达长期主义、家族、交付或品质。避免做成破败或怀旧滤镜。

### M24 收藏生活
艺术、书、家具、器物、唱片与设计作品表达审美选择；只挑少量有关系的物件，不堆“昂贵道具”。

### M25 家族传承
用门、树、长桌、藏书、建筑或物件表达时间跨度。避免老人儿童牵手等直白套路。

### M26 城市权力
高层俯瞰或城市界面，有秩序与距离感；项目明确但不加金色发光标记。适合CBD、城市核心和顶豪。

### M27 城市坐标
只用一套点、线、圆、经纬结构或建筑轮廓图形系统表达地段与品牌坐标。地图关系必须准确。

### M28 未来建筑
先进材料、超净结构、玻璃、暖银金属与受控光域。禁止蓝色HUD、代码、电路板和霓虹赛博城市。

### M29 品牌超级符号
从项目字母、Logo结构、建筑轮廓或核心概念提炼一个可长期复用的符号。不得直接变形官方Logo；先区分识别资产与创意图形。

### M30 Typography First
文字占视觉约50%–70%，建筑为弱背景。适合品牌宣言、悬念与强文案；前提是文案简短有力。标题、案名和必要信息直接进入最终画面，与图像共同构图，不交付分离的无字底图。

## 人物、光线、色彩与材质

### 人物导演

不能只写“高端人物”。至少说明人数、年龄感、位置、画面占比、朝向、动作、服装、是否看镜头、与空间关系。示例：一名约35–45岁人物位于右下，身高占画面约11%，45度背侧，不看镜头；穿无Logo的浅灰针织和深灰长裤，自然缓行，不持香槟。

人物不是默认添加项，也不是默认排除项。建筑、品牌与地块任务根据尺度感、生活方式、受众代入和素材条件决定是否出现人物；服务、社群与生活任务可主动推荐人物；大师必须基于真实素材与身份。

### 光线

至少写明时间、天气、方向、软硬、冷暖、对比、阴影、高光与天空。示例：清晨7点阴天漫射光从右前方45°进入，略暖；受光面浅暖灰，背光面暗约1级；玻璃仅轻微灰蓝反射；天空无太阳和云缝光，整体低对比。

不要把示例固化成默认答案。正午硬光、夕阳、蓝调时刻、商业夜景、节庆灯光和高对比棚拍都可进入首推方案；夜景尤其适合城市核心、商业、开盘、灯光系统和天际线价值表达。控制曝光层级、玻璃反射、招牌亮度、环境补光和主次光源，不因“夜景”本身降低推荐度。

### 色彩

至少写明主色、辅色、明度、饱和度、冷暖差和面积比例，并说明慎用色及其使用条件。“高级灰”不合格。没有品牌、内容或可读性冲突时写“无预设禁止色”，不要为了填写字段而排除红色、金色或其他大众常用色。

#### 红色与金色

红色、金色和黑金都是正常商业配色候选，不降低推荐优先级，也不只限定于节庆场景。春节、中式礼序、喜报、获奖、开门红、周年庆、交付、品牌庆典和既有VI尤其适合评估红金体系；大众传播、强销、节点活动及需要高识别度的任务中，红色也可进入首推方案。

- 红色需说明偏朱红、绛红、枣红、砖红或正红，避免无层次的高亮纯红铺满画面。大面积用红时通过深浅同色层次、负空间、纸张/漆面/织物等真实材质控制刺激度。
- 金色需说明香槟金、暖金、古铜金或哑光金，并指定拉丝、烫金、金属箔、压凹凸或低反射金属等物理质感。避免黄色渐变冒充金属、满版高光、廉价发光描边和无来源金粉。
- 红金同时出现时确定主次，但不设置固定比例：可采用红色主场+金色点缀、金色主视觉+深红结构，或根据品牌资产形成较均衡组合。比例由传播强度、信息层级、材质面积和画幅决定；避免红底、金字、金边、金粉、烟花和传统纹样同时抢主视觉。
- 红绸、奖杯、金粉、舞台、金色立体字均是可用视觉语言。评价红绸的纤维、重量、褶皱尺度与重力；金属的色相、拉丝/箔面、反射率、边缘与厚度；奖杯的原创结构与象征关系；金粉的景深、受光与分布层级；舞台的空间尺度与主次。问题是材质失真、模板化组合和多个元素同权，不是元素本身。使用多个元素时先把它们合并成一个核心装置或明确主从。
- 喜报/获奖以核心数字或奖项为第一层级，红金只服务信息权重；春节/中式先从窗格、剪纸、漆器、织物、印刷套色、建筑礼序等一种机制建立系统，不拼贴“年味符号大全”。

### 字体风格描述

不推荐或默认点名需要付费授权的商用字体。若用户没有提供企业字体，只输出设计师可执行的字体形态，并提醒成稿阶段选择已取得授权或明确可商用的字体文件。

至少描述：黑体/宋体/圆体/手写或展示体类别、字面大小、字宽、笔画粗细与粗细对比、转角、重心、字腔、字重、字距、行距、数字风格和中英文字体关系。例如：

> 主标题使用现代窄身黑体方向，字面偏大、重心略高、横竖笔画接近等粗、转角利落，采用中黑至粗黑字重，字距收紧约-2%至-4%；副标题使用中性无衬线细体方向，正常字宽，字距放宽约8%至12%，与主标题形成重量差；数字采用等宽或近等宽结构，不使用装饰性斜体。

不要只写“高级黑体”“国际化字体”“某某字体同款”，也不要把字体名称当成视觉判断。

### 材质

写材料、表面、纹理、反射。示例：偏暖浅灰天然洞石，哑光，保留细小孔洞和不均匀纹理，不镜面抛光；边缘接受柔和暖光，整体低反射。

不能只写“高级金属”“高级丝绸”。材质至少说明：材料类型、厚度或重量感、表面处理、纹理尺度、反射强弱、边缘状态、光源位置、接触阴影和与相邻材质的差异。减少元素不等于提高质感；若只剩底色和大字却没有构图机制、材质证据与光线关系，同样判为低完成度。

## 专项执行

- 大师人物：优先建筑杂志（人物+建筑）、事务所（人物+图纸/模型）、策展（人物+作品/材料）；避免论坛嘉宾海报。
- 地块/区位：真实航拍和地图为事实底图；AI不得改红线、道路、地标、方位和配套。创意发生在叙事和图形层。
- 服务：表现开门、引导、接待、整理、礼宾、递物、空间维护或私密服务瞬间；强调“服务被体验”。
- 品牌活动/IP主视觉：先锁定媒介、IP角色、第一视觉、文字上限和配色结构。主视觉默认只用一个IP或主图形、一句主题和1–3个内容暗示，不把每项活动都画出来。IP主导且采用手绘时，人物和环境默认统一为手绘；若使用摄影或3D混合，必须说明混合逻辑。
- IP保真：四视图优先于单张情绪图。逐项核对头身比例、正侧背轮廓、五官、标志性配件、品牌色和标志位置；允许动作与媒介变化，不允许为了“高级化”擅自拉长身体、缩小头部或删除识别资产。
- 活动系列：主视觉锁定IP动作语言、核心图形、主色、Logo位与标题结构；具体活动内容在辅助展板和系列延展中展开。
- 喜报/获奖：先核获奖主体、奖项、数字、范围、年份、来源和证据。信息默认分为：主标题“喜报/荣耀时刻/品牌自有荣誉标题”→“某单位/某项目荣获”→奖项全称→名次/等级/数量→Logo；根据语气选用，不机械固定“喜报”。结果通常是第一视觉，但不得缺失获奖单位或项目。视觉先选一个主机制：数字装置、奖项雕塑、品牌超级符号、建筑与数字融合、红绸空间、信息排版等；红金、黑金、奖杯、金粉和舞台均可使用，按质感与主从关系判断，不做元素禁用清单。
- 通知/公告：可读性高于氛围图。
- Campaign：Fixed DNA含主色、核心图形、Logo位置、标题逻辑、质感、光线、材质、网格和字体；Flexible DNA含场景、主体、次级色和信息结构。

## 俗套与AI味检测

高警戒的是缺乏项目依据的模板化组合，例如同时使用镜面金色动物、皇冠、金粉、城市光轨和星空。鹿、马、树、地球、孔雀、鲸鱼、香槟、游艇、月亮、羽毛以及金色本身均非禁用；有品牌隐喻、产品证据或节庆语境时可以使用，但需控制主体数量、材质真实性和信息层级。

逐项检查AI味：假天空、镜面水、塑料石材、过亮玻璃、错误建筑结构、过度完美植物、假人物、不合理反射/阴影、光源冲突、多余粒子、过度锐化、游戏CG和奇观化比例。

插画/IP额外检查：吉祥物是否变形，头身比例是否漂移；IP、人物和场景是否像由同一插画师完成；是否同时堆叠粗圆字、大头人物、贴纸、水花、泡泡、彩虹色与满屏笑脸；色相是否超过预设结构；修改配色或尺寸时是否意外改动已确认构图与IP。

## 稳定生产路径

| 任务 | 推荐流程 |
| --- | --- |
| 纯KV | 图像与文字层级同步构图 → 生成/合成 → 在同一画布校正中文与Logo → 图文一体成稿 |
| 大师人物 | 真实人物保真编辑 → 背景与信息同步构图 → 同一画布完成文字、Logo与细节 |
| 建筑/项目素材 | 真实图为锚 → 扩图/调色/环境融合 → 结构复核 → 同一画布完成全部排版 |
| 地块 | 真实航拍与信息层级同步构图 → 调色扩图 → 同一画布完成红线、文字与Logo |
| 战报/通知 | 信息设计为主 → AI背景仅辅助 |
| 喜报/获奖 | 核实主体与奖项 → 锁定信息层级 → 建立一个核心视觉机制 → 生成/合成 → 校正文字、Logo与材料细节 |
| Logo | 构图阶段确定位置与安全区 → 在完整画面中置入官方源文件；不让模型重绘 |

完成任何一条生产路径后，再做两层验收：先看方案是否成立（传播目标、信息、构图、核心机制），再看生成是否准确（Logo、中文、比例、色彩、材质、光源与多余元素）。方案成立但生成失败时，只修执行问题，不随机更换创意方向。
