# 设计判断知识库

这是审美决策的核心。按“内容→观看方式→大形→文字→造型/色彩→细节”工作。先解决最影响观感的一层，再处理下一层。把漂亮形容词换成画面关系，但不靠精确到小数的比例制造专业感。

## 1. 识别真正的设计问题

| 看到的现象 | 先检查什么 | 有效动作 | 常见无效动作 |
| --- | --- | --- | --- |
| 看起来很满、很累 | 高对比轮廓是否遍布全画面；文字是否被细节包围 | 把细节集中到叙事区，降低背景边缘对比，合并零碎色块 | 只缩小所有东西，留下碎片化空隙 |
| 看起来很空、没设计 | 大形有无张力；文字是否只是贴在空白处 | 放大裁切、改变文字行式、建立图文共用轴线或形状呼应 | 加粒子、光晕、纹理填满空白 |
| 像模板 | 是否可以只换标题就用于任何项目 | 从真实建筑、活动动作、品牌语言提炼专属关系 | 换一种流行材质或更复杂的装置 |
| 像儿童活动 | 角色头身、表情和字形是否都在卖萌 | 保留适合受众的角色，调整人体结构、动作、色块和字重 | 把所有人拉成长腿、全部改灰 |
| 标题不好看 | 行式是否拥挤、字面是否松散、字重是否与图像竞争 | 先调整分行、宽度、字面和间距，再判断是否定制 | 直接加金线、立体描边与星芒 |
| 质感廉价 | 材料是否同样光滑；高光是否覆盖大面积 | 区分主材与陪材，控制高光形状、反射与接触 | 给所有表面加颗粒或压暗 |
| 插画与IP不统一 | 轮廓、形体概括、明暗级数、色彩角色是否相容 | 对照原资产检查造型，再统一边缘和受光 | 只叠一层纸纹；只说“同一画风” |
| 高端但无聊 | 是否只剩安静空间和空泛文案 | 找一个具体观看角度、可辨识物件或有力度的标题组织 | 再减元素、再用细字、再增加留白 |

“好看”还包括任务适合度：通知首先要读得清，节庆要有参与吸引力，销售要有产品或信息证据。不要用艺术展览标准排斥热烈商业传播。

## 2. 画面骨架与观看路径

不要在工具里固定套用这些名称；用它们比较形状和阅读体验。以下比例都是具体起稿的可调线索。

| 骨架 | 具体组织方式 | 容易成立的任务 | 做坏的原因与修复 |
| --- | --- | --- | --- |
| 大字主导 | 短标题占主要视觉面积，图像嵌在字旁或局部负空间，辅助信息沿共用边界排列 | 喜报、开门红、品牌主张 | 标题太长还强行铺满；缩短拟题或分出语义层级，不压扁汉字 |
| 非对称并置 | 文字块与图像块错开重心，靠共用基线/边缘连接 | 社群、价值点、邀请 | 两块均匀各占一半像PPT；改变一方尺度，取消多余框线 |
| 全景中的静区 | 场景铺满，文字落在图像原本平缓的色面 | 园林、夜景、建筑 | 后加黑色渐变硬救文字；先改变裁切、曝光分区或图像位置 |
| 裁切近景 | 一个真实细部越过画边，留下未展示部分，让观者补全 | 工艺、建筑细节、静物 | 裁切后无法识别对象；保留结构转折和必要上下文 |
| 斜向动势 | 人物/道具/字块沿一条斜向移动，其余元素给方向让路 | 运动、竞赛、活力活动 | 各元素朝不同方向；统一姿态和空间推进，不只是歪标题 |
| 围合或环形 | 多角色/物件围绕活动动作，中央留给信息或行为焦点 | 邻里、亲子、聚会 | 人人一样大且正对镜头；建立近远、遮挡、动作差异 |
| 满版纹样＋信息锚点 | 一个基础单元重复形成丰富背景，文字进入清晰的色块/留空结构 | 春节、市集、周年庆 | 每格不同、每格同样抢眼；固定重复语法、减少局部差异 |
| 对称礼序 | 轴线、两翼和中央信息共同形成仪式，可平面亦可空间化 | 中式庆典、邀请、交付 | 镜像装饰像现成边框；改变内外疏密，突出材料或字形 |
| 图文穿插 | 文字与图像共享遮挡/层次，少量笔画进入图形 | 年轻品牌、文艺活动 | 遮住关键字部件；把穿插移到字外沿或语义不受损处 |
| 网格与档案 | 真实图、局部、引文和说明按少数明确模数排列 | 建筑设计、团队、服务、通知 | 全部卡片相同大小；用一张主图/一个主信息打破均分 |

标题在上、插画在下只是候选之一。不要因为用户在上一张图认可过它，就取消下一张图的骨架比较。

## 3. 好看依赖的六种关系

### 大小与重量

面积不是视觉重量的唯一来源：高饱和红块、黑色粗轮廓、亮白IP、清晰人脸、小而密的纹样都可能比大面积灰背景更抢眼。标题放大后，先看它是否压倒角色表情和活动动作；插画缩小时应连同装饰/背景细节一并重分配，不能只缩人物。

以手机缩略图看成几块大色面。通常应能辨识一个先看位置和后续阅读路径，但允许多个焦点按序展开。黑白缩略图用来发现竞争，不能单独裁决依赖色彩的作品。

### 疏密与节奏

留白需要成片、能引导视线；均匀撒在元素之间的小缝不等于呼吸感。丰富画面也需要一处信息停靠区。可以让边缘密、中心疏，或一侧密、另一侧开阔；不能全画面平均密度。

例如端午纹样：大粽叶占据三个连续节拍，小五色线只在两个转角回应；标题区保留完整色面。比“粽叶、龙舟、艾草、香囊各摆一个”更有整体性。

### 统一与例外

统一基本形状、边缘处理、色彩角色与排版轴线；再保留一个有理由的例外形成记忆。全都统一成相同大小会僵硬，全都特殊会混乱。

例如红金喜报：大部分文字为沉稳平面字，只有结果数字采用金属厚度。若标题、数字、奖杯和Logo全立体，例外就消失了。

### 形状与内容

圆形不天然代表团圆，向上不天然代表成长，金色不天然代表尊贵。先看画面中的动作或结构能否支撑含义。具体的共同包粽动作比没有关系的圆环更能表达邻里；真实院落的开合关系比任意门洞更能表达归家。

### 色彩与对比

先给颜色分角色：环境底、内容主色、阅读色、强调色/品牌资产色。颜色数量不是唯一标准；多色可由相近明度和固定分布形成系统，双色也会因面积和对比失控而刺眼。

热烈红色可以大面积使用：让主字有清楚明度差，让红底中的纹理退后，让金属只在指定表面体现反射。静奢可以使用明亮蓝白、深绿或浓紫；判断材料与色块边界，不用米白代替决策。

### 细节与观看距离

远看靠字面、大形和色块；近看靠边缘、笔画、手部、材质与图文对齐。把工夫投在承担识别的地方。背景每片叶子都清楚会与主体竞争；主标题的细线若缩小后消失，再精巧也不能承担识别。

## 4. 从内容提炼创意

先列可证实的内容资产：一个活动动作、一处真实空间特点、一种地域材料、一句独特主张。再选择最有视觉潜力的资产，尝试以下动作，而非随机找象征物：

- **放大局部**：把平时略过的缝、折、边缘、手势变成主角，保留可识别上下文。
- **改变观看距离**：从宏大园林转向窗边框景，或从单人转向共同活动的俯视关系。
- **重复形成节奏**：把一片叶、一块砖、一笔字组织成连续图形；重复的是语法，不是复制素材堆数量。
- **图文共享结构**：标题横势接续水院，字块模数回应窗格，副题与建筑轴线对齐。
- **留下发生前后的一瞬**：手将要投入、门刚打开、光正落在纸上。动作要能读懂，不能为了气氛画错事实。
- **建立恰当反差**：粗字配轻盈线描、浓色配清爽空区、丰富纹样配安静信息面。两者需由色彩或形状联系。

“把粽叶变成河”“把数字变奖杯”只是可能的隐喻。若变形导致功能错误、项目无关或画面更难读，就使用直接表现。原创性也可以来自精确裁切、角色调度和排版。

## 5. 方向比较与审美判断

三案比较时问：哪案最能让目标受众记住正确内容？哪案大形最清楚？哪案有可描述的独特关系？哪案能用当前素材和工具实现？选择理由应引用具体画面，不用“更高级、更国际”互相循环解释。

若三个方案都像“文字＋精美物件摆在空房间”，重新比较骨架。若三个方案都成立，不为不同而把其中一案强改成不合适的媒介。

审稿优先顺序：事实/品牌关键错误 → 内容与阅读 → 构图重量与疏密 → 造型与色彩 → 细节。前两层有硬问题先处理；后几层通过实际对比改善，不使用无依据的88分门槛。

## 6. 使用设计推演库

推演卡是原创教学示例。每张解释“具体画面—成立原因—常见失败—修正—迁移边界”；不是直接复制的提示词成品，也没有宣称真实投放效果。

| 当前设计需要 | 优先阅读 |
| --- | --- |
| 邻里叙事、现代节庆、成熟IP、热闹群像 | 节庆与角色设计推演 C01–C06 |
| 红金、字体、圈层、繁复纹样、强传播 | 品牌与商业设计推演 C07–C12 |
| 保真建筑、园林、服务、区位、通知 | 真实素材与信息设计推演 C13–C18 |
| 预热、案名、开放、开盘、加推、倒计时 | 销售节点设计推演 C19–C24 |
| 宽厅、露台、采光、工艺、园林、智慧服务 | 产品价值设计推演 C25–C30 |
| 花集、音乐、阅读、冬日、运动、非遗 | 季节与社群设计推演 C31–C36 |
| 交付、多项目、轮播、户外、舞台、年报 | 系列与载体设计推演 C37–C42 |
| 同一需求缺少图文、配色与材质选择 | 图文与色材组合方法 |
| 学习2025–2026的具体设计做法 | 2025-2026设计观察 R01–R11 |

使用时选择最相关的一张和一个可比较的另一方向，只迁移成立的关系。比例、颜色、人物数量、媒介和标题文案全部需要重新适配。没有合适卡片时，使用本页的判断方法构建新方案，不强行匹配。
