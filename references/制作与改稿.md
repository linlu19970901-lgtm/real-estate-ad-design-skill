# 制作与改稿

用于把方案落实到可靠成稿，避免说明正确而画面错误。工具与权限以实际环境为准；技能不能赋予不存在的精确编辑能力。

1. 素材分层与事实

## 1. 素材分层与事实

收到素材后实际查看并识别其用途：官方Logo、建筑/园林/室内、人物、地图/航拍、证书/数据、IP设定、既有KV。文件名可帮助定位，不能替代内容核对。

- **事实资产**：建筑结构、地图关系、人物身份、奖项数据，保持真实。艺术转译允许改变笔触和综合色，不增删影响价值认知的配置。
- **品牌资产**：Logo、IP、品牌色、既有系列规则。遵守已提供VI；没有VI时采取保守使用，不凭空宣称“符合全部规范”。
- **创意内容**：非事实背景、装饰、概念图形、媒介与构图，可随方案调整。概念场景不能冒充实景。

正式Logo用官方矢量/透明文件直接置入，保持比例、净空与允许的色版；安全区由VI优先决定，不能把通用百分比当VI。缺少源文件但需要首稿时，不伪造Logo：可以完成概念预览，指出正式置入尚待文件。

真实素材艺术化时，核对轮廓、体块、道路、水面、园林轴线、主要植物和功能区位置。需要时采用叠加或并排比较；笔触允许概括细节，不允许多出花坛、喷泉、建筑或配套。地图使用可靠底图，红线、道路连接、地名与距离不能靠图像模型猜。

事实核查覆盖本轮实际风险：日期、奖项主体与全称、排名口径、规划/现状、价格条件、服务承诺、肖像与来源。民俗动作或特定器具不确定时查官方文化机构等可靠来源；找到的玩法若有地域差异要依活动实际版本。广告法律与平台规则采用现行官方信息，不能承诺一次检查覆盖所有法律。

按实际出现的内容核验，不每张图都输出清单：

| 内容 | 核验对象 |
| --- | --- |
| 收益、保值、升值、融资 | 是否包含未经证实或不适合广告的承诺，当前规则与证据是否支持 |
| 排名、唯一、第一、奖项、销量 | 主体、口径、范围、时间、来源；不能仅换近义词规避问题 |
| 交通、教育、户口、配套 | 现状与规划、测量条件、服务或政策依据，不能把可能性写成保证 |
| 价格、面积、优惠、稀缺数量 | 单位、条件、期限和来源，限制信息不能因版式而不可读 |
| 地图、官方机构、国家标识与敏感文化符号 | 底图来源、表达准确性、使用场景与适用规则；不虚构背书，不凭词表机械判断 |
| 实景、效果图、艺术演绎与人物 | 来源称谓、实际授权与身份，不将概念画面标成项目实景 |

发现具体问题时指出内容、原因与可行替代表达；证据不足就标待核实。不要输出“全面安全”式结论，也不把未经核验的疑虑都升级为违规。

## 2. IP识别与小样验证

先从参考中提取识别卡，使用真正看到的特征，而非通用形容词：

- 正面与侧面的头部轮廓、头宽与身体宽度关系、头高与身体高度关系。
- 五官间距和位置、眼形、嘴形、顶部/耳侧/胸前配件的位置与大小。
- 身体、四肢、脚掌的长度和形状；姿态变化时哪些结构仍保持。
- 品牌色、胸标和服装；哪些颜色是固有色，哪些只是参考图中的光影。

可估计关键比例帮助对照，但不假装精密测量。四视图优先用于转向判断，单张图没有提供的侧背结构不自行当作已知；优先选择有参考支持的朝向。

**何时先做小样。** IP第一次进入明显不同的媒介、原图曾反复变形、或人/IP融合是主要风险时，先内部制作IP与一位相邻人物/一小段环境的风格小样。简单的已有同风格IP置入不必新增步骤。小样不要求用户先选，不作为技能内置配图。

**小样检查。** 先看轮廓与五官，再看明暗、边缘、颜色、接触。身份不对先修身份，不能用“更统一”作为改坏角色的理由。人物和IP不需要相同头身比或相同材质；需要相称的画法和共同空间。

**失败处理。** 首次失败先明确错误部位并编辑；同一关键问题经过两轮定向修复仍未改善，停止重复原提示词，改用可用的原资产保真编辑、分层合成或有参考支持的姿态。仍不能保证时标明未解决，不声称保真通过。不能反过来要求用户接受一个已变形的IP。

## 3. 生成前执行卡

内部用一张短卡固定最容易漂移的内容：

| 项目 | 记录内容 |
| --- | --- |
| 基准 | 新方案或已选图的路径/版本；参考图各自用途 |
| 文案 | 原文、拟稿状态、层级、分行、对齐 |
| 画面 | 画幅、主要字块与图像位置、视觉重量、留白关系 |
| 视觉 | 造型、媒介、主辅色角色、细节集中区 |
| 资产 | 官方Logo、IP参考、真实结构与事实 |
| 本轮变化 | 具体对象、位置、幅度、允许联动与保留项 |

不要给所有参数虚构数值。比例是草图控制值，不保证生成工具精确执行；出图后需目视核对。正向描述优先，硬约束集中到关键资产、文字与本轮保护项。

## 4. 生产路径与停损

- **纯概念KV**：先确定图文关系，生成完整预览；按实际能力校正文字/资产，交付一张完整设计。
- **正式Logo/精确中文/数字**：构图阶段预留与排好位置，在同一画布可靠置入或排版。工具不支持时明确仍为预览，不伪称正式成稿。遵守当前环境的图像编辑工具要求，不用技能绕过工具规则。
- **真实建筑/园林**：以原图为基准裁切、调色、保真编辑或艺术转译；完成后对照结构。
- **地图/通知/多数字**：优先可靠排版、矢量或信息工具；图像生成只承担可变氛围，不生成事实底图和二维码。
- **用户要提示词/设计沟通**：交付可执行说明与原文，不擅自扩展成大量图片。

中文定制字不稳定时，优先改为结构清楚的字形或采用可控排版；只有用户允许改变设计时才降低装饰复杂度，不能擅改已确认标题。不要把生成图里的拼写错误作为风格。

一般先出首推稿；如需探索，只围绕具体不确定项生成少量候选。每轮改变能解释的变量。同一问题两轮没有改善就重新判断制作方法；不为“达到完美”无边界生成。关键缺陷无法修复时交代实际状态，其他已授权且能完成的工作继续完成。

## 5. 版本与改稿

先确定用户指的版本。能从上下文、缩略图和路径确认就直接继续；只有多个同名版本无法区分时才问，不把版本管理交给用户。

每轮保留：基准图、用户已认可部分、本轮修改、合理联动、检查结果。记录服务当前项目，不自动成为跨项目偏好。用户明确说“以后这类都……”时再按其范围沿用。

例如：

> 基准：用户认可的端午首稿。保持标题内容/行式、角色位置、叶片形态与主色关系；改为3D媒介。联动材料、阴影和局部明暗；不重构背景空间或增加新角色。完成后与基准并排检查大小位置。

把反馈分到正确层：

- “标题再大、插画再小”：调整两个整体字块/图像组，再看背景细节与平衡；不把IP单独缩小。
- “IP大一点”：IP独立缩放，检查与动作、遮挡和地面接触的联动；不修改参考头身比。
- “画风不统一”：定位轮廓、造型、明暗或材质，只修改造成冲突的变量；若水彩最能统一边缘与叠色，可正常选用。
- “画面太挤”：先看高对比边缘和文字净区，可能需要重排而非均匀缩小。
- “不高级/不好看”：提出最主要的具体原因并修正，保留已成立的颜色与元素。米白、黑金、浓色或空间场景都可作为修正方向，但必须说明它具体解决了哪一处关系。

如果已认可版本比最新修改更好，回到它继续编辑，不以“最新版”为唯一基准。局部问题优先局部编辑；完整重排或更换媒介可能需要整图处理，但仍对照已确认的关系。

## 6. 实际验收

看图后记录结论，不能从提示词反推成功。按需要使用实际缩略图、原尺寸局部和基准对照，不要求每次制作复杂检查板。

**第一层：阅读与美感。** 先把实际图与方案里最关键的图文关系比较：原计划的平面折边是否变成满屏飘带？奖项是否从主字组退成注释？图文并置是否变回上字下图？这类变化要重新判断，不能只看元素都出现。在手机预览尺度看，主题能否读懂？字块与图像有无清楚关系？细节是否集中？空白是否成片且有用？色彩是否支持主次？是否只是通用背景换标题？纯文字、满版纹样、群像都按自身设计目标判断。

若采用中心稳定构图，另查：主标题是否达到光学居中；两侧是否共享造型、材质、色彩与细节语言；视觉重量是否均衡而非机械镜像；辅助信息是否也无必要地全部堆在中轴。若采用单侧构图，确认另一侧确有建筑、人物、产品或方向性光影承重；没有依据的靠边不算设计变化。

**第二层：执行。** 对照完整原文、Logo、数字、IP关键特征、器具动作、建筑/地图结构。检查文字笔画、角色手部、物件数量、接触阴影以及本轮重点修复部位。小到无法看清的项记为“无法确认”，不能判通过。

**媒介选择回归。** 回看首选方向：是否仅因“常见、容易俗、之前用过”而排除了某种媒介、配色或主体？如果是，重新放回等权候选，用当前任务的内容匹配、图文关系、素材兼容和执行可控性比较。反向检查四类典型适配：空气与柔光主题应能主动选择水彩；纸张、石材或编辑感主题应能主动选择米白；夜间礼仪和金属光主题应能主动选择黑金；抽象概念需要空间化时应能主动选择艺术装置。通过不等于四类都要使用，而是适合时能成为首选。

**第三层：改稿回归。** 与基准比较：标题行式/大小、主图位置/面积、IP体型、角色数量、配色与已认可细节是否漂移？若局部修复破坏了更重要的部分，应修回或改用基准。

报告只写实际观察：

- 可写：“标题已改为一横排；IP外轮廓更接近参考，但胸标仍需校正。”
- 不写：“完全保真、全部统一、绝不漂移”，除非相应证据确实支持；通常避免绝对承诺。
- 不把“生成成功”“高分辨率”“自评90分”当作审美通过。

导出后检查文件能打开、尺寸正确、文字在缩略图可读。用户遇到加载困难时给轻量预览，保留正式尺寸版本；不要以压缩解决设计问题。实际保存按运行环境要求完成，生成测试图不自动进入技能知识库。

## 7. Skill迭代验证

更新规则后分别验证“能作出不同且合适的设计判断”和“图像执行能跟上”。固定一组真实需求作为回归，同时加入未见过的简报检验迁移：

| 需求 | 重点观察 |
| --- | --- |
| 中秋博饼＋IP | 文化动作、角色关系、身份与画风；不要只看有无六颗骰子 |
| 端午营销 | 是否由任务选骨架和媒介，而非无理由复用上一图 |
| 豪宅圣诞 | 能否表达邀请与品牌，人物是否适当，标题是否有设计关系 |
| 红金喜报 | 是否保留热烈传播并处理好信息，而非机械压暗或删成公告 |
| 园林艺术转译 | 构图是否改善且真实结构保持 |
| 繁复市集/无装饰纯文字 | 能否根据内容建立相反密度的有效构图 |
| 体系发布/建筑摄影 | 能否分别选择中心非镜像均衡与有依据的单侧停靠，而非一律居中或一律靠边 |
| 抽象时间主题 | 能否区分时刻、周期、过程、积累与代际，并用观看关系表达，而非自动添加钟表、沙漏或光轨 |

可用独立任务执行检查泛化，给执行者技能与原始简报，不提供预期答案或预设诊断。需要生成时使用同等信息和相近预算比较，不能用不同执行条件制造优劣。

区分四类证据：文件/引用校验、文字方案测试、实际图像检查、用户采用反馈。每类只支持对应结论；没做同题图像对照就不宣称首稿成功率提升，没做真实IP对照就不宣称IP保真已验证。把失败转成局部修改或生产方法调整，不把一次偏好上升成通用禁令。
