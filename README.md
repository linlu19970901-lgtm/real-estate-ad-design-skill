# 地产广告设计助手

帮助地产营销与物业团队，把需求、素材和改稿意见转成具体的主视觉设计。

重点是构图、字体、色彩、角色和图像之间的关系。资料足够时直接做首稿，减少来回填写需求表。

[在 ChatGPT 中使用](https://chatgpt.com/skills?skill_id=6aa1fc62f9608191a4958a5812ac8ce4) · [English](README_EN.md)

## 可以做什么

- 品牌发布、建筑园林价值点、社区节庆、IP活动、豪宅邀约。
- 喜报战报、通知公告、地图区位、真实素材设计。
- 创意提案、图文一体成稿、给设计师或AI平台的执行说明。
- 针对现稿调整构图、标题、画风和IP，保留已经认可的部分。

实际生成与精确编辑能力取决于所用平台和工具。

## 核心内容

**设计判断知识库**  
从画面骨架、大小、疏密、色彩和图文关系入手，判断为什么不好看、优先改哪里。

**42组设计推演**  
覆盖节庆与IP、红金商业、真实建筑园林，并扩展到预热开盘、加推倒计时、宽厅露台、季节社群、交付、轮播、户外和舞台。每组都有具体起稿、成立原因、常见失败、修正方法和适用边界。这些是原创教学方案，不是真实投放案例或已验证成稿。

**字体与媒介执行**  
把标题排版、字形、平面插画、厚涂、版画和3D写到可以执行的程度。换画风时分别控制版式、造型、媒介、色彩与细节。

**2025–2026近期设计研究**  
11项可追溯来源，结合代表画面分析文字、图形、色彩与系列方法，并写出地产转译和适用边界。分别标注作品年份与公开日期，不把近期转载当成新作品。部分为国内媒体刊载的传播样本，作者或创作时间未确认时明确注明。

**图文与色材组合**  
8种图文关系、10种色材搭配，以及中文标题和同一需求的多方向起稿方法。按任务读取，不要求一次加载全库。

**制作与改稿**  
对照素材检查Logo、IP和真实结构；用基准版本保护已认可设计。检查实际图片，不靠自评分或提示词长度证明质量。

## 设计原则

水彩、摄影、厚涂、3D、平面图形；米白、红金、黑金、明亮多色；人物、静物、建筑、艺术装置等均是等权候选。先说明它们能为当前项目解决什么，再比较内容匹配、素材兼容、阅读效率与制作条件。常见、曾经失手或连续使用都不构成降权理由；适合时可以继续使用。

## 怎么用

在支持技能的环境中使用 `real-estate-ad-design`；本仓库名为 `real-estate-ad-design-skill`。

直接提供需求：

> 为社区端午活动做一张主视觉，希望年轻、热闹、有设计感。已有Logo和IP设定，直接完成首推稿。

或上传现稿：

> 保持这版构图、标题和配色，改成厚涂油画风。IP体型按设定保留，请检查改稿有没有影响已确认的部分。

也可以只要方案：

> 给我三套真正不同的红金喜报方向，写到设计师可以起稿，不必生图。
