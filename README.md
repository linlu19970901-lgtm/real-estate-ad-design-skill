# 地产广告设计助手

面向地产营销与物业活动的主视觉设计 Skill。它把项目内容、真实素材和改稿反馈转化为可执行的构图、字体、版式、色彩、材质、IP与图像关系，并在工具支持时完成图文一体成稿。

重点不是套风格，而是先判断这张图应当让人记住什么，再用适合项目和传播场景的视觉关系把它做成立。

[在 ChatGPT 中使用](https://chatgpt.com/skills?skill_id=6aa1fc62f9608191a4958a5812ac8ce4) · [English](README_EN.md)

## 可以做什么

- 品牌与体系发布、案名亮相、豪宅形象、人文与精神主张。
- 建筑园林、产品价值、销售节点、交付服务、真实素材整合。
- 社区节庆、IP活动、喜报获奖、通知公告、区位地图与系列传播。
- 从创意提案、图文一体首稿到定向改稿、设计师或AI平台执行说明。

实际生成与精确编辑能力取决于所用平台和工具。

## 最新设计方法

### A/B/C选案流程

用户说“按流程走”时，先压缩需求，提供三个在观看体验、图文关系或叙事上真正不同的方向，明确首推并停在选案节点；用户选定后再展开执行与出图。用户已指定方向或要求直接出图时，不重复提案。

### 高级简约方案的默认席位

“整场质感＋低干预设计”通常作为B方向备选；在品牌发布、人文价值、豪宅形象、精神主张和案名亮相中，默认提升为A方向。它不是固定的米白、黑金或陶土模板，而是让摄影、单色色域、石材、织物、金属、压纹、接缝或连续光影承担主要视觉。

### 中心稳定，不等于镜像对称

多数正式地产主视觉优先测试“中心信息稳定＋两侧视觉语汇统一”：主标题居中或接近中轴，两侧共享材质、曲线、光影、色域与细节密度，但允许冷暖、疏密和起伏不同。有明确建筑、人物、产品、景观或方向性光线承重时，单侧排版可以成为首推。

### 字体、版式与IP

先处理信息分级、标题断句、字块尺寸、对齐和光学中心，再决定字形、装饰与材料。IP先确定传播职责、识别核、动作、道具、环境接触和文字关系，不把角色作为最后贴上的角标。

### 时间成为观看关系

“恒久、未来、生长、陪伴、焕新、抵达”等概念先区分为时刻、周期、过程、积累或代际，再通过连续光色、材料层积、路径推进、冷暖迁移、新旧证据等表达。钟表、日历、沙漏和光轨不是默认答案。

## 基本原则

水彩、摄影、厚涂、3D、平面图形；米白、红金、黑金、明亮多色；人物、静物、建筑和艺术装置均为等权候选。是否适合由当前内容、素材、阅读和制作条件决定；同一种媒介也应通过构图、造型与图文关系形成项目差异。

尺寸优先服从用户与载体；未指定时，主视觉/KV可按16:9、手机海报按9:16、小红书图文按3:4起稿。正式Logo、建筑、地图、奖项、数字和IP按真实资产检查。
