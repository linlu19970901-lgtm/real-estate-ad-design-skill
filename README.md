# 地产广告设计助手

面向中国房地产营销与物业传播的 AI Skill。把不完整需求、项目素材和模糊反馈，转成设计师可直接起稿、图像生成工具可直接执行的视觉方案。

## 适用场景

- 地产主视觉、案名发布、品牌预热与Campaign
- 建筑、园林、会所、户型和服务价值海报
- 社区活动、节庆活动、IP活动与豪宅圈层活动
- 喜报、获奖、战报、通知和公告
- 区位地块、大师人物、航拍与真实素材合成
- 现稿诊断及“不高级、太地产、太AI”等反馈翻译

## 能做什么

1. **快速判断**：资料足够时直接提出首稿假设，只追问会影响事实、合规或制作方式的关键信息。
2. **三套真差异方案**：从第一视觉、叙事、构图、媒介和人物角色上建立差异，不只换颜色。
3. **图文一体设计**：标题、信息、Logo和图像从构图阶段同步进入画面。
4. **真实素材保护**：锁定建筑、园林、区位、人物、奖项、Logo与IP识别资产，避免生成模型篡改事实。
5. **具体执行规格**：明确画幅、主体比例、镜头、光线、色彩、材质、人物可见度、标题系统和生成提示词。
6. **生成与改稿闭环**：完成判断、锁版、生成/合成、验收和定向修正，不把明显错误图直接交付。
7. **设计与合规质检**：检查媒介惯性、人物使用、字体装饰、IP一致性、材质、Logo、数据和广告表达。

## 设计判断重点

- 高级感不等于灰调、极简、米白或低饱和。
- 红色、金色、人物、夜景和装饰都可使用，关键是项目依据、主次、材质与光线。
- 水彩、3D、版画、厚涂、摄影和拼贴均按任务选择，不固定一种“高级答案”。
- 豪宅圈层活动优先以空间、艺术装置或收藏品为主体；人物默认无人或远景虚焦。
- 正式KV标题必须形成视觉系统，装饰进入笔画、负形、边框、材质或空间关系。
- IP可以与人物共存，但必须同时保证IP识别资产和整张画面的媒介一致。

## 使用方法

将本目录安装到支持 `SKILL.md` 的智能体环境，然后直接提供项目资料与目标。

```text
使用 $real-estate-ad-design，为高端住宅的圣诞圈层活动设计横版主视觉。
已有项目Logo，画面不要出现清晰真人，请直接给三套可执行方案并生成首推稿。
```

也可以上传现有设计：

```text
使用 $real-estate-ad-design 诊断这张海报。
领导反馈“太土、字体没设计感”，请定位原因并给出具体修改动作。
```
